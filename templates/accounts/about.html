SeedView

SeedView is an image analysis platform for sainfoin (Onobrychis) seed research. It detects and counts individual seeds and unthreshed pods in photographs of seed samples, so seed lots can be counted quickly and reproducibly instead of by hand.

{# ── How it works ───────────────────────────────────────────────────── #}

How it works

  • Each image is resized and sent to a YOLO26 object-detection model running on a serverless GPU endpoint.
  • The model returns a box, class (seed or pod) and confidence score for every object it finds.
  • Detections below the job's confidence threshold are dropped; the rest are counted and drawn over the image.
  • Results can be exported as per-image counts, per-detection box coordinates, or annotated overlay images.

Counts are model estimates. Touching or overlapping seeds, debris, and uneven lighting can all affect accuracy — spot-check the overlays, especially for new sample setups.
